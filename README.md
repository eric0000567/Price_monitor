## 🚀 新功能特色

### 📈 K線圖表功能
- **專業K線圖**：顯示當前選擇加密貨幣的蠟燭圖（Candlestick Chart）
- **完整OHLC數據**：顯示開盤價、最高價、最低價、收盤價
- **60根K線顯示**：每個時間週期固定顯示 60 根 K 線
- **多種時間週期**：支援 1分鐘、5分鐘、15分鐘、1小時、4小時、1天 K 線
- **幣安K線數據**：直接從幣安 API 獲取歷史 K 線數據，無需本地累積
- **智能更新**：根據選擇的時間週期自動調整更新頻率
- **漲跌顏色**：綠色K線表示上漲，紅色K線表示下跌
- **中文支援**：使用系統中文字體，無亂碼問題
- **適中尺寸**：800x400 像素，方便查看不占空間
- **原生顯示**：使用 macOS Quick Look 原生浮動視窗，置頂顯示，方便查看

## 🛠️ 安裝和設定

### 1. 安裝依賴套件

```bash
pip install -r requirements.txt
```

### 2. 配置幣安 API

有兩種方式設定 API 密鑰：

#### 方式一：使用環境變數（推薦）

**方法 A：直接設定環境變數**
```bash
# macOS/Linux
export BINANCE_API_KEY="您的幣安API密鑰"
export BINANCE_API_SECRET="您的幣安API密碼"

# Windows
set BINANCE_API_KEY=您的幣安API密鑰
set BINANCE_API_SECRET=您的幣安API密碼
```

**方法 B：使用 .env 文件**
```bash
# 創建 .env 文件
cat > .env << EOF
BINANCE_API_KEY=您的幣安API密鑰
BINANCE_API_SECRET=您的幣安API密碼
EOF

# 記得將 .env 文件加入 .gitignore（如果使用 Git）
echo ".env" >> .gitignore
```

**方法 C：在啟動時設定**
```bash
BINANCE_API_KEY="您的API密鑰" BINANCE_API_SECRET="您的API密碼" python crypto_menubar_monitor.py
```

#### 方式二：直接在配置文件中設定

編輯 `config.json` 文件：

```json
{
    "binance_api": {
        "api_key": "您的幣安API密鑰",
        "api_secret": "您的幣安API密碼",
        "testnet": true,
        "trading_enabled": false
    },
    "trading_settings": {
        "default_quantity_usdt": 10,
        "default_leverage": 1,
        "default_stop_loss_percentage": 5,
        "default_take_profit_percentage": 10,
        "order_confirmation": true
    }
}
```

> 🔒 **安全提醒**：建議使用環境變數方式，避免將 API 密鑰直接寫在配置文件中，特別是當項目需要版本控制時。

### 3. 獲取幣安 API 密鑰

1. 登入 [幣安官網](https://www.binance.com)
2. 前往「API 管理」頁面
3. 創建新的 API 密鑰
4. **重要**：為了安全起見，建議先在測試網測試

#### 測試網設定
- 測試網址：https://testnet.binance.vision/
- 註冊測試帳號並獲取測試 API 密鑰
- 在 config.json 中設定 `"testnet": true`

#### 正式交易設定
- 確保 API 密鑰有交易權限
- 在 config.json 中設定：
  - `"testnet": false`
  - `"trading_enabled": true`

## 🔧 使用說明

### 啟動應用程式

```bash
python crypto_menubar_monitor.py
```

或使用腳本：

```bash
./run_menubar.sh
```

### 💰 交易功能使用

1. **啟用交易功能**
   - 在 config.json 中設定有效的 API 密鑰
   - 設定 `"trading_enabled": true`

2. **現貨交易**
   - 選擇「💰 交易功能」→「📈 現貨交易」
   - 選擇市價或限價買入/賣出
   - 設定交易數量和止盈止損

3. **合約交易**
   - 選擇「💰 交易功能」→「⚡ 合約交易」
   - 選擇做多/做空/平倉
   - 設定槓桿倍數和止盈止損

4. **查看帳戶資訊**
   - 「💼 帳戶餘額」：查看現貨和合約餘額
   - 「📊 持倉資訊」：查看當前合約持倉
   - 「📋 訂單紀錄」：查看最近的交易訂單

### 🚨 價格警報設定

1. 點擊「🚨 警報設定」
2. 設定高價和低價警報閾值
3. 當價格觸及閾值時會收到系統通知

### 🎨 顯示模式

- **簡潔模式**：顯示價格和變化
- **完整模式**：顯示完整資訊
- **僅符號**：只顯示貨幣符號

### 📈 K線圖表功能使用

1. **選擇時間週期**
   - 點擊選單中的「📈 走勢圖」→「⏰ 時間區間」
   - 可選擇：1分鐘K、5分鐘K、15分鐘K、1小時K、4小時K、1天K
   - 每個週期固定顯示 60 根 K 線
   - 預設為 15 分鐘 K 線

2. **開啟K線圖**
   - 點擊「📈 走勢圖」→「👁️ 顯示走勢圖」
   - 圖表會以 macOS Quick Look 原生浮動視窗形式顯示
   - 視窗會自動置頂顯示，方便隨時查看

3. **查看圖表**
   - 圖表會立即在 Quick Look 浮動視窗中顯示完整的歷史K線
   - 從幣安 API 獲取歷史 K 線數據，無需等待本地累積
   - 根據選擇的時間週期，顯示對應的 K 線數據
   - 綠色K線表示該時段上漲（空心），紅色K線表示下跌（實心）
   - 使用 macOS 原生 Quick Look，穩定可靠，不會干擾其他應用程式

4. **時間週期與更新頻率**
   - **1分鐘K**：60根 1分鐘K線，每 30 秒更新
   - **5分鐘K**：60根 5分鐘K線，每 1 分鐘更新
   - **15分鐘K**：60根 15分鐘K線，每 2 分鐘更新
   - **1小時K**：60根 1小時K線，每 5 分鐘更新
   - **4小時K**：60根 4小時K線，每 10 分鐘更新
   - **1天K**：60根 1天K線，每 30 分鐘更新

5. **K線圖表元素**
   - **K線實體**：開盤價和收盤價之間的矩形
   - **上影線**：從實體頂部延伸到最高價的線
   - **下影線**：從實體底部延伸到最低價的線
   - **綠色K線**：收盤價高於開盤價（上漲），空心顯示
   - **紅色K線**：收盤價低於開盤價（下跌），實心顯示
   - **黃色價格線**：顯示當前最新收盤價
   - **參考線**：方便觀察價格位置

6. **關閉K線圖**
   - 點擊「📈 走勢圖」→「🙈 隱藏走勢圖」
   - 關閉預覽程式視窗

> 💡 **提示**：K線圖功能需要安裝 Pillow 套件。如果未安裝，選單會顯示提示訊息。

## 🐛 常見問題

### Q: 為什麼交易功能顯示為未啟用？
A: 請檢查：
1. API 密鑰是否正確設定
2. `trading_enabled` 是否設為 `true`
3. 網路連接是否正常

### Q: 如何切換到正式交易？
A: 
1. 獲取正式的幣安 API 密鑰
2. 在 config.json 中設定 `"testnet": false`
3. 確保 `"trading_enabled": true`

### Q: 止盈止損功能如何使用？
A: 在下單對話框中：
1. 勾選「啟用止損」或「啟用止盈」
2. 設定百分比（如 5% 表示價格變動 5% 時觸發）
3. 確認下單後會自動設定止盈止損訂單

### Q: 走勢圖功能無法使用怎麼辦？
A: 請檢查：
1. 是否已安裝 Pillow 套件：`pip install Pillow`
2. 網路連接是否正常（需要從幣安 API 獲取價格資料）
3. 預覽程式是否可以正常開啟圖片檔案

### Q: 為什麼走勢圖沒有更新？
A: 
1. 確認走勢圖功能已開啟（選單顯示「🙈 隱藏走勢圖」）
2. 走勢圖每30秒更新一次，請耐心等待
3. 檢查終端機是否有錯誤訊息
4. 確認當前加密貨幣有正常的價格更新

### Q: K線圖的數據從哪裡來？
A: 
1. K線圖直接從幣安 API 獲取歷史 K 線數據
2. 不需要在本地電腦累積數據
3. 每次打開K線圖都會獲取最新的歷史數據
4. 每個時間週期固定顯示 60 根 K 線：
   - 1分鐘K：60根 = 1小時歷史
   - 5分鐘K：60根 = 5小時歷史
   - 15分鐘K：60根 = 15小時歷史
   - 1小時K：60根 = 2.5天歷史
   - 4小時K：60根 = 10天歷史
   - 1天K：60根 = 60天歷史

### Q: 如何切換不同的時間週期？
A: 
1. 在選單中點擊「📈 走勢圖」→「⏰ 時間區間」
2. 選擇想要的時間週期（1分鐘K、5分鐘K、15分鐘K、1小時K、4小時K、1天K）
3. 如果K線圖正在顯示，圖表會立即從幣安獲取新的 K 線數據並更新
4. 所有時間週期都固定顯示 60 根 K 線
